# Roadmap — Portfólio EFC Tecnologia / EFCSYS

## Concluído
- [x] Identidade visual premium (preto/graphite/dourado/prata)
- [x] Páginas públicas: Home, Projetos, Detalhe, Sobre, Tecnologias, Contato
- [x] Admin protegido: Dashboard, Projetos, Categorias, Tecnologias, Mídia, Mensagens, Configurações
- [x] Banco de dados com RLS, roles e bucket de mídia privado
- [x] SEO: metadados, sitemap, Search Console
- [x] Formulário de contato com persistência e notificação por e-mail
- [x] Publicação Etapa 7
- [x] Hardening de segurança (mensagens e storage)

## Próximas etapas

### Etapa 8 — Polimento do painel administrativo (concluída)
- [x] Upload de imagens direto no formulário de projeto (card, hero, OG)
- [x] Reordenação drag-and-drop na galeria de mídia
- [x] Preview de e-mail e de compartilhamento social (OG) no admin
- [x] Validação de slug único e feedback de erros do banco


### Etapa 9 — Performance e experiência (concluída)
- [x] Lazy loading e carregamento prioritário da imagem principal do projeto
- [x] Cache de consultas (1 min) e pré-carregamento de páginas ao passar o mouse
- [x] Link "Pular para o conteúdo" e validação de navegação por teclado
- [x] Verificação dos fluxos críticos (Home, Projetos, Sobre, Contato) sem erros de console

### Etapa 10 — Conteúdo e conversão
- [x] Página de artigos/cases técnicos (blog leve)
- [x] Depoimentos de clientes
- [x] Rich snippets / JSON-LD para projetos e artigos
- Integração com analytics

### Etapa 11 — Integrações externas (concluída)
- [x] Botão/link direto para WhatsApp com mensagem pré-preenchida
- [x] Campo de agendamento (Calendly) no painel e cartão na página de Contato

### Etapa 12 — Polimento geral (concluída)
- [x] Varredura de console em todas as páginas (desktop e mobile) — zero erros
- [x] Revisão visual de Home, Projetos, Sobre, Artigos, Tecnologias e Contato nos dois formatos
- [x] Confirmação das animações de revelação e do botão flutuante de WhatsApp
